# GraphRAG GUI

GraphRAG的图形用户界面，使GraphRAG的强大功能更易于使用。

## 功能特点

- **配置管理**：轻松设置和管理GraphRAG配置
- **索引控制**：通过图形界面构建、更新和管理知识图谱索引
- **查询执行**：使用多种搜索方法查询您的知识图谱
- **提示词调优**：简化提示词生成和调优过程

## 安装

1. 确保已安装Python 3.10或更高版本
2. 克隆本仓库
3. 安装依赖项：

```bash
pip install -r requirements.txt
```

## 使用方法

1. 启动GUI应用程序：

```bash
python graphrag_gui.py
```

2. 使用配置选项卡设置项目目录和配置文件
3. 使用索引选项卡构建或更新知识图谱
4. 使用查询选项卡执行搜索查询

## 系统要求

- Python 3.10+
- GraphRAG 2.2.0+
- PyQt5
- qasync
